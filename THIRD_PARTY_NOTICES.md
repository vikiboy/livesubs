# Third-party notices

LiveSubs is built on other people's open-source work and models. Thank you to all of them.
This file lists everything the app, its test harness and its showcase use, with each licence.
Each licence's full text ships with its package (Swift Package Manager and npm fetch them).

## Models (downloaded on the device, not included in this repository)

- **Whisper** by OpenAI ([openai/whisper](https://github.com/openai/whisper), MIT), as Core ML
  conversions by Argmax ([argmaxinc/whisperkit-coreml](https://huggingface.co/argmaxinc/whisperkit-coreml), MIT).
- **TranslateGemma 4B** by Google, as the 4-bit MLX conversion
  [mlx-community/translategemma-4b-it-4bit](https://huggingface.co/mlx-community/translategemma-4b-it-4bit).
  Gemma is provided under and subject to the Gemma Terms of Use found at
  [ai.google.dev/gemma/terms](https://ai.google.dev/gemma/terms). LiveSubs doesn't
  redistribute the weights: the app downloads them straight from Hugging Face when you
  choose **Get TranslateGemma**.
- **Parakeet TDT 0.6B Japanese** by NVIDIA (CC BY 4.0), via FluidAudio. Used only in the Mac
  harness's comparisons.
- Apple's on-device **Speech** (SpeechTranscriber) and **Translation** frameworks, part of iOS.
